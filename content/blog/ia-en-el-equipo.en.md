Bringing AI into the team isn't installing a tool. It's changing how a task is written before it is coded.

## Spec first

Before asking an agent for code, we write what it has to do, what it must not do and how it is verified. That spec later feeds the PR review.

## What worked

- Short internal guides, with examples from the repo itself.
- Shared skills for repeated tasks.
- Documenting legacy services before migrating them.

## What didn't

Using it for architecture decisions without context. A person is still needed there.
